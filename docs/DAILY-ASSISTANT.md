# 日常功能使用

飞书和微信共用本人的提醒、待办、随手记、联系人和邮件记录。可以直接发送自然语言，也可以使用下面的命令。

| 功能 | 可以这样说 | 固定命令 |
|---|---|---|
| 今日概览 | 我今天有什么安排 | `/今日` |
| 稍后提醒 | 把编号 r_xxx 的提醒推迟十分钟再提醒我 | `/稍后提醒 r_xxx 10分钟` |
| 查已触发提醒 | 查一下刚刚触发的提醒 | `/提醒 全部` |
| 完成待办 | 将编号 t_xxx 的待办标记完成 | `/完成 t_xxx` |
| 保存随手记 | 记一条笔记，标题项目配置，正文项目使用 Python 3.12 | `/记事 项目使用 Python 3.12` |
| 检索随手记 | 找一下关于 Python 的笔记 | `/找笔记 Python` |
| 查看全文 | 查看编号 n_xxx 的笔记 | `/查看笔记 n_xxx` |
| 修改随手记 | 把编号 n_xxx 的正文改为项目使用 Python 3.13 | 自然语言修改 |
| 删除指定笔记 | 删除编号 n_xxx 的笔记 | `/删除笔记 n_xxx` |
| 邮件记录 | 查一下我的邮件记录 | `/邮件` 或 `/草稿` |
| 邮件全文和状态 | 查看编号 e_xxx 的邮件内容 | `/查看邮件 e_xxx` |
| 修改未发送邮件 | 把编号 e_xxx 的邮件主题改为下周交付 | 自然语言修改 |

## 今日概览

显示今日到期、已经逾期及未设有效截止日期的待办，以及今天剩余的提醒。日期按助理的时区计算，默认 Asia/Shanghai。日期型截止时间在当天结束前计入“今日到期”，带具体时间的截止时间过去后计入“已逾期”。已完成待办不纳入概览。

概览显示各组总数和部分项目，完整列表可用 `/待办`、`/提醒` 查询。提醒旁会显示原通知渠道。

## 稍后提醒

可延后尚未触发的单次提醒，也可让已经触发的单次提醒再提醒一次。再次提醒会发到当前聊天。

对于每天、工作日或每周的重复提醒，系统创建一条额外的单次提醒，原周期继续执行。尚未发出的旧通知重试会取消。已经被消息平台接受的通知无法撤回。

可设置 1–10080 分钟，省略分钟数时固定命令默认 10 分钟。自然语言中的提醒不明确时，助理会查询已有记录或询问。

## 随手记

笔记持久保存，按标题和正文中的关键词检索，支持查看全文、修改和删除指定记录。检索是文本包含匹配，百分号和下划线按普通字符处理。飞书保存的笔记也可从微信检索。

## 邮件

`/邮件`、`/草稿` 查询本系统保存的草稿和已发送邮件记录，状态以中文显示。`/查看邮件` 展示保存的主题、收件人、正文和发送状态。

待发送或明确发送失败的邮件可修改，修改后展示完整新预览。确认内容后，输入 `/发送邮件 e_xxx` 发信。已发送、正在发送和结果待核查的邮件保留当前记录，需要新内容时另建草稿。

这些查询读取助理自己的记录。QQ 收件箱读取、附件、抄送和定时发信尚未接入。
